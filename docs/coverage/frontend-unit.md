# Frontend unit test coverage

Coverage of `frontend/src` from the Vitest unit tests. CI appends a row on each push to `main` where the tests pass. Do not edit the rows by hand.

Coverage shows which code ran during the tests, not that it behaves correctly. There are no thresholds.
