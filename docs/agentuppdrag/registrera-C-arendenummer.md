## 2. Plan

Föreslagen spectext:

- "Ingår": `Automatiskt vid sparning: id, ärendenummer (ticketNumber, SR-<år>-<1000 + id>), status ("Nytt"), tidpunkt (createdAt)`.
  Den gamla raden kallade `id` för "ärendenummer". Nu skiljs de åt.
- AK-4, Then: `Svaret är 201, ärendet sparas med status "Nytt", id, ärendenummer och tidpunkt.
  Svaret innehåller ticketNumber i formatet SR-<år>-<1000 + id>`.

Skillnader mot prompten, tagna upp i steg 0:

1. `TicketResponse.From` finns inte. Svaret byggs direkt i `CreateTicket.cs` (`new TicketResponse(...)`).
   `ticket.TicketNumber` läggs till där, efter `Id`, och ingen `From`-metod skapas. Samma upplägg som PR #7.
2. `CreateTicketInput` är `Omit<Ticket, ...>`. `'ticketNumber'` läggs till i Omit, annars kräver
   formulärets indata fältet. PR #7 gör inte detta, så raden kan ge en mergekonflikt.
